# lake-library-poster

[![make.fun · the-poster-for-a-place-that-i-2-20261121-0539](https://make.fun/badge/the-poster-for-a-place-that-i-2-20261121-0539.svg)](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539?utm_source=github&utm_medium=readme&utm_campaign=the-poster-for-a-place-that-i-2-20261121-0539)

A travel poster for the Lake Library, a place that does not exist: a library
beneath a lake, where a river runs between shelves that climb to a ceiling of
projected stars, residents sleep in hammocks among the stacks, and knowledge
is open to all, never closed. Rendered in pointillism.

## Run it

```sh
python3 main.py
```

Writes the poster to /output/entry.png (1024x1024 PNG, under 1 MiB).
